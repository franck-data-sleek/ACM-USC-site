# ACM @ USC — website redesign

Clickable preview of the proposed uscacm.org redesign ("Night Build" direction), prepared by Franck Leveneur (Data-Sleek) for the ACM @ USC board.

## What's here

`ACM-USC-site-preview/` — 12 static HTML pages, linked together. Open `index.html` in a browser.

| Page | File |
|---|---|
| Home | `index.html` |
| Home (phone layout) | `home-mobile.html` |
| Projects | `projects.html` |
| Project page (Stardom) | `project-stardom.html` |
| Events | `events.html` |
| TrojanHacks hub | `trojanhacks.html` |
| Blog | `blog.html` |
| Blog post (light mode) | `blog-post.html` |
| Team + alumni | `team.html` |
| Partner With Us | `partners.html` |
| Join | `join.html` |
| FAQ | `faq.html` |

Values in brackets — `[N]`, `[Date]`, `[Project name]` — are placeholders for the board to fill in. Fonts load from Google Fonts, so an internet connection is needed for the intended look.

## Status

Design preview only — not the production site. Proposed next step: rebuild as an Astro static site in the club's existing GitHub Pages repo (`uscacm/uscacm.github.io`), with content in Markdown and Pages CMS for non-technical editing.
